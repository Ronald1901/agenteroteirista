# Roteirista Harness v7.7.2

Objective Loop real com B descompilado, comparação formal A×B, release challenge e failover automático de quota para subagentes.

## Funções cognitivas

1. DNA Analyzer
2. B Decompiler
3. Rewriter
4. Objective Critic
5. Release Challenger / Second Opinion

Os agentes `*-fb-*` são executores ocultos da mesma função sob outro modelo. Eles só são chamados após falha de quota/modelo e não acrescentam novas etapas ao pipeline.

O arquivo final sempre fica em `roteiro final/` na raiz.

Formato soberano: A=voz/forma, B=conteúdo/ordem/tamanho, F=layout editorial. Todo final usa GANCHO + BLOCOS numerados com subtítulo + FECHAMENTO.
